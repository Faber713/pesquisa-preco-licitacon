INSTRUCOES PARA USAR O PROJETO NO NOTEBOOK DE CASA
===================================================

Projeto salvo no GitHub privado:
https://github.com/Faber713/pesquisa-preco-licitacon


1. INSTALAR O GIT
-----------------

No notebook de casa, instale o Git for Windows:

https://git-scm.com/download/win

Depois de instalar, reinicie o VS Code se ele ja estiver aberto.


2. CLONAR O PROJETO NO VS CODE
------------------------------

Abra o VS Code.

Pressione:

Ctrl + Shift + P

Digite:

Git: Clone

Cole este link:

https://github.com/Faber713/pesquisa-preco-licitacon.git

Escolha uma pasta do computador para salvar o projeto.

Quando o VS Code perguntar se deseja abrir o repositorio clonado, clique em Open.

Como o repositorio e privado, o GitHub pode pedir login. Entre com a conta Faber713.


3. INSTALAR AS BIBLIOTECAS DO PYTHON
------------------------------------

No VS Code, abra o terminal:

Terminal > New Terminal

Dentro da pasta do projeto, rode:

pip install -r requirements_web.txt

Se o comando acima nao funcionar, tente:

python -m pip install -r requirements_web.txt


4. RODAR O SISTEMA
------------------

Depois de instalar as bibliotecas, rode:

streamlit run app_web.py

Ou clique no arquivo:

iniciar_interface_web.bat


5. ARQUIVOS QUE NAO FORAM PARA O GITHUB
---------------------------------------

O GitHub recebeu o codigo do projeto, mas alguns arquivos grandes/dados locais ficaram fora de proposito.

Nao foram enviados:

licitacon.sqlite
bases_dados/
resultado_da_busca_item.csv
build/
__pycache__/

Se precisar usar esses dados no notebook de casa, copie separadamente por pendrive, HD externo, OneDrive, Google Drive ou outro meio.

O arquivo licitacon.sqlite tem mais de 5 GB, por isso nao deve ser enviado pelo GitHub normal.


6. COMO SALVAR ALTERACOES NOVAS NO GITHUB
-----------------------------------------

Depois que modificar o projeto no notebook de casa, use estes comandos no terminal do VS Code:

git add .
git commit -m "Descreva aqui o que mudou"
git push

Exemplo:

git add .
git commit -m "Melhorias na interface web"
git push


7. COMO ATUALIZAR OUTRO COMPUTADOR
----------------------------------

Quando voltar para outro computador e quiser pegar as mudancas mais recentes do GitHub, abra a pasta do projeto no VS Code e rode:

git pull
